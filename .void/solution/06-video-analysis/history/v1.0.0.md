## 版本定位
`v1.0.0` 确立了 `06 analysis` 的第一条正式可运行主线：
- 显式输入一个 `selection-package.json`
- 消费已导出的短视频切片
- 从每段视频抽取关键帧
- 拼接当前 Obsidian 记忆文档
- 通过 `OpenRouter` 调用 `Gemini 2.5 Flash`
- 必要时回退到 `Gemini 2.5 Pro`
- 输出结构化 JSON 和 Markdown 摘要

## 已明确的设计
该版本已经锁定：
- 不做 selection 结果自动发现。
- 不做复杂记忆检索与 rerank。
- 不做多 provider 抽象。
- 当前主模型为 `Gemini 2.5 Flash`。
- 当前备选模型为 `Gemini 2.5 Pro`。
- 当前主输入形态为“关键帧 + 文本上下文”，不是原生视频直传。

## 当前已知边界
该版本的稳定边界如下：
- 只有在 `selected_clips` 非空时才进入正式分析。
- 若 05 selection 因边界状态过滤导致 `no_candidates`，06 不会自动回退到 `point_clips`。
- 记忆当前采用全量 Markdown 拼接，仍可能引入噪声。
- 关键帧路径已经可用，但连续动作细节仍不如未来的视频直传路径自然。

## 后续替代方向
后续版本优先考虑：
- 为 `no_candidates` 场景设计受控的人工或半自动降级路径。
- 评估是否引入原生视频输入。
- 评估是否把记忆读取升级为独立子系统。
